# 세계 지도 하이라이트 🗺️

**나라 이름이나 약자를 입력하면 세계 지도에서 그 나라가 하이라이트되는 웹 게임입니다.**

학습 카드로 먼저 외우고, 열다섯 가지 모드로 시험까지 볼 수 있는 한 개의 파일짜리
웹사이트예요. 빌드·설치가 필요 없고 외부 라이브러리도 쓰지 않습니다(웹폰트 하나만
예외) — [`index.html`](index.html) 을 브라우저에서 열기만 하면 바로 실행됩니다.
**한국어·영어 두 언어**를 지원하며, 오른쪽 위 **언어 버튼**으로 언제든 전환할 수
있어요(메뉴·설명·문제·힌트·순위 단위까지 모두 번역). **친구와 한 기기로 즐기는
로컬 1대1 대결**, **음성으로 답하기**, **위치 학습** 같은 새 기능도 있습니다.

처음 열면 **모던한 앱 런처 스타일의 홈 화면**(그룹별 색으로 구분된 **깔끔한 아이콘
카드** 그리드)에서 원하는 놀이를 고릅니다. 카드를 누르면 곧바로 시작하지 않고 **설정
화면**이 먼저 떠서 **지역·전쟁·지표·제한 시간** 등을 고른 뒤 `시작하기`를 눌러야
게임이 시작돼요 — 그전까지 **타이머는 돌아가지 않습니다**(맞히기·찾기 등은 첫 입력/
클릭 때 타이머 시작). 언제든 **홈** 버튼으로 돌아올 수 있어요. 바탕은 세련된
**모노크롬(흑백)** 이지만 **하이라이트에는 색을 입혔습니다**(찾은 나라=초록, 문제=금색,
순위=파랑 등). **Gowun Dodum**(구름 도돔) 글꼴, 부드러운 애니메이션, 그리고 **모바일**
(손가락 오므리기 확대·큰 버튼)까지 지원합니다. 홈 화면은 **neal.fun 스타일의 가로로
넓은 카드**에 게임 이름을 큼직하게 얹었어요.

**▶ 라이브 데모:** https://darkerapple.github.io/mapgame/
(저장소 **Settings → Pages → Source: `main` 브랜치 / `/ (root)`** 로 설정하면 켜집니다.)

## 기능

- **입력창에 나라 이름을 입력** → 해당 국가가 지도에서 밝게 하이라이트됩니다.
  - 한글 이름: `대한민국`, `미국`, `일본`, `남아프리카공화국` …
  - 영문 이름: `Brazil`, `france`, `Japan` …
  - 약자(ISO 코드): `KR`, `US`, `JP`, `UK`, `UAE`, `DRC` …
  - 별칭도 인식: `호주`(오스트레일리아), `버마`(미얀마), `터키`(튀르키예), `남아공` …
- **전 세계 208개 나라·지역** — 지도에 그릴 수 있는 180개국 폴리곤 +
  싱가포르·몰디브·모나코 같은 작은 섬·도시국가 28개는 점(마커)으로 표시.
- **지역별 학습·시험** — 대륙을 잘게 나눈 **하위 지역**(예: 동아시아·동남아시아·
  남아시아·중앙아시아·서아시아, 유럽 4개, 아프리카 5개, 아메리카 등)으로 작게
  쪼개서 외우고 시험 볼 수 있어요.
- **읽기 쉬운 학습 목록** — 학습 카드 모드에서는 나라 이름을 지도에 욱여넣지 않고
  옆의 **목록 패널**에 또렷하게 보여 주고, 지도에는 현재 나라 한 곳만 이름표를
  붙입니다. 작은 나라가 많은 지역(아프리카·유럽)도 글자가 겹치지 않아요.
  국기만 보고 맞히는 **자가 테스트(이름 가리기)** 도 있습니다.
- **한국어 / English 전환** — 오른쪽 위 언어 버튼 한 번으로 UI·게임 설명·전쟁
  트리비아 문제·힌트 문장·순위 지표와 숫자 단위(억/조 ↔ million/billion)까지
  통째로 바뀝니다. 나라 이름 입력은 원래부터 한글·영문 모두 인식해요.
- **색을 입힌 하이라이트 · 만족스러운 피드백** — 맞혀야 할 나라는 지도에서 **밝은
  금색**으로 칠해 한눈에 보이고, 찾은 나라는 **초록**, 순위표는 **파랑 그라데이션**,
  정복은 **초록 그라데이션**으로 표시돼요. 정답/찾기에는 화면 가운데 **큰 ✓ 배지**가
  터지듯 나타나고(오답은 ✗), 트리비아는 정답 초록·오답 빨강 **색 테두리**로 표시해요.
- **친구와 로컬 1대1 대결** — 이름 맞히기·지도에서 찾기·국기 퀴즈·수도 퀴즈·힌트
  퀴즈를 **한 기기로 번갈아** 즐길 수 있어요. P1·P2 점수와 **차례 표시**가 뜨고,
  지도 게임에서는 **누가 맞힌 나라인지 색(P1 파랑·P2 주황)으로 구분**해 칠해집니다.
  **틀리면 차례를 잃지 않고 −1점**(0점 미만은 안 내려감)으로, 맞힐 때까지 계속
  도전하거나 `넘기기`로 차례를 넘길 수 있어요. 정해진 문항 수를 마치면 **승자**를
  가려 줍니다.
- **모바일 최적화** — 좁은 화면에서는 상단바를 **한 줄(홈·모드·언어)** 로 압축하고
  도움말 푸터를 접어 **지도를 더 크게** 보여 줍니다. 홈은 한 줄 카드로 바뀌어요.
- **로컬 프로필 · 기록 저장** — 홈에서 **회원가입/로그인**하면 게임별 **최고 기록·누적
  점수·플레이 횟수**가 저장되고, 결과 화면에서 **🏆 최고 기록 갱신**을 알려 줘요.
  계정은 **이 브라우저에만 저장되는 로컬 프로필**(서버 전송 없음, 비밀번호는 로컬에서
  해시)이며, **다른 기기로 옮기기**는 프로필의 **백업 코드/파일 내보내기 → 가져오기**로
  합니다.
- **접근성** — 시맨틱 제목 구조(`main`/`h1`/`h2`)와 카드·버튼 **aria 라벨**, **키보드
  포커스 표시**, 피드백/차례의 **aria-live** 안내, 모달의 `role="dialog"`·Esc 닫기를
  지원합니다.
- **비슷한 게임끼리 묶은 홈** — *배우기 · 이름·위치 맞히기 · 퀴즈 · 비교·순위 · 도전 ·
  트리비아* 로 나눠 원하는 놀이를 찾기 쉬워요.
- **음성으로 답하기** 🎤 — 텍스트 입력 모드에서 마이크 버튼을 누르고 나라 이름을
  말하면 인식해서 답합니다. 발음이 조금 어긋나도 **가장 가까운 나라로 관대하게**
  맞춰 줘요(브라우저 음성 인식을 지원하는 환경에서만 나타납니다).
- **작은 섬·도시국가 마커 크기 자동 조절** — 확대할수록 점(마커)이 **작아져** 확대
  시 너무 커 보이던 문제를 없앴습니다.
- **타이머 · 초기화 · 확대/축소·이동**(마우스 휠 / 손가락 오므리기 / 드래그 /
  `＋`·`－`·전체 버튼). 맞히기·찾기·국기 퀴즈의 제한 시간은 **고른 지역의 나라
  수에 맞춰 자동 조절**돼요(작은 지역에서 시간이 남지 않도록).
- **한글 IME 입력 지원** — 조합 중 눌린 Enter는 무시하고, 조합이 끝난 뒤에만 확인.
- 모노크롬 테마 · 인라인 SVG 아이콘 · 등장/하이라이트 애니메이션 · 모바일 대응.

## 열다섯 가지 모드

| 모드 | 설명 |
|---|---|
| **자유 탐색** | 자유롭게 입력해 위치를 확인. 지도를 눌러도, 마우스를 올려도 이름이 보여요. |
| **학습 카드** | 지역을 고르면 **읽기 쉬운 나라 목록**(국기·한글·영문·ISO 코드)이 지도 옆에 뜨고, 지도에는 **현재 나라 하나만** 이름표가 붙어 깔끔합니다. **국기를 크게** 보여 주고, 목록·지도를 눌러 이동, `섞기`로 순서 변경, **`이름 가리기`** 로 국기만 보고 맞히는 **자가 테스트**, 다 외우면 **`이 지역 시험`** 으로 바로 퀴즈까지. |
| **위치 학습** 🆕 | 이름을 보고 지도에서 **눌러 찾으며 위치를 익히는** 모드. **타이머가 없고** 틀리면 정답 위치를 잠깐 **밝혀 줘서** 자연스럽게 외워집니다. 다 익힐 때까지 못 맞힌 나라는 **다시 나와요**. |
| **이름표 놓기** | 나라 **이름표를 지도의 알맞은 땅 위로 끌어다 놓는** 드래그 게임. 맞는 나라에 놓으면 딱 붙고, 틀리면 돌아옵니다. (마우스·터치 모두 지원) |
| **이름 맞히기** | 지도에 표시된 나라의 이름을 90초 동안 최대한 많이 입력. |
| **지도에서 찾기** | 제시된 이름을 보고 지도에서 직접 **눌러** 찾기. 90초. |
| **국기 퀴즈** | 국기(🇰🇷 🇧🇷 🇪🇬 …)를 보고 나라 이름 입력. 90초. |
| **수도 퀴즈** 🆕 | 나라(국기+이름)를 보고 **수도 이름을 입력**. 한글·영문 수도 모두 인정하고, 음성 입력·1대1도 지원. |
| **더 큰 나라?** 🆕 | 두 나라 중 **인구·면적·GDP가 더 큰 쪽을 고르는** 캐주얼 게임. 고르면 두 나라의 실제 값이 공개돼요. 제한 60초 동안 연속으로. |
| **힌트 퀴즈** | **힌트를 보고 나라를 맞히는** 퀴즈. **📜 역사적 사실·⚔️ 현재 분쟁**(나라 이름은 가린 채)이 먼저 나와 알아맞히기 쉽고, 이어서 지역·**면적 세계 순위(예: 상위 50위 안)**·반구/해안·기후·인구·인구밀도·정부 형태·경제·고도·국경 수 등 **다양한 단서를 매번 다른 순서로** 공개합니다(`다음 힌트`). **힌트를 적게 볼수록 점수가 높고**, **`🔥 확실한 힌트`** 는 이름 첫 글자·인접국 나열·수도·**국기**처럼 결정적이지만 점수를 많이 깎는 강한 단서예요. **라운드마다 난이도가 섞여** 나와요 — **쉬움**(큰 단서가 먼저·8점)·**보통**(10점)·**어려움**(막연한 단서부터·**14점**)으로, 어려운 라운드를 적은 힌트로 맞힐수록 점수가 큽니다. 지역 선택 가능. |
| **정복 모드** 🆕 | 지도의 나라를 **여러 번 눌러 칠하는** 게임. 한 번 누르면 살짝, **여러 번(예: 5번) 누르면 가득 칠해져 잠기고 다시 그려지지 않아요.** 제한 시간 안에 그 지역을 **전부 칠하면 🏆 트로피**. 나라가 많은 대륙(아프리카 등)은 **누르는 횟수를 줄여** 균형을 맞췄어요. |
| **지역별 도전** | 고른 지역(대륙 또는 하위 지역)의 **모든 나라**를 입력. 다 채우면 완성! |
| **전세계 도전** | 제한 시간(1·3·5분) 안에 주권국 197개국을 최대한 많이. `X / 197` 진행 표시. |
| **순위표** | 나라를 **지표별 순위**로 봅니다 — 인구·면적·인구밀도·GDP(명목)·1인당 GDP·평균 고도·평균 기온. 지도가 값에 따라 **밝기로 칠해지고**(밝을수록 상위), 목록/지도를 눌러 정확한 값을 확인. 지역 필터 · 오름/내림차순. |
| **전쟁 트리비아** 🆕 | **Kahoot 스타일 4지선다 퀴즈.** **13개 전쟁 · 총 351문항**의 큰 문제 은행에서 **매번 무작위 6문항**(6·10·15 중 선택)을 뽑아 풀어요. 카테고리(세계대전·냉전기·근대·**고대·중세**·**현대 분쟁**) 또는 **특정 전쟁**을 고를 수 있고, **카테고리 칩을 눌러 원하지 않는 카테고리는 숨길** 수 있습니다. 문제는 연도 암기보다 **원인·전개·의미를 묻는 이해형**이 대부분이에요. 정답은 **초록**, 오답은 **빨강** 테두리로 표시되고, **숫자·A~D 키보드 단축키**로도 답할 수 있어요. 한국어·영어 모두 지원. |

> 이름 맞히기 · 지도에서 찾기 · 국기 퀴즈 · 수도 퀴즈 · 힌트 퀴즈는 설정에서
> **혼자 하기 / 1 대 1**을 고를 수 있어요. 대부분의 모드는 상단(또는 설정)의
> **지역 선택**으로 범위를 좁힐 수 있습니다(“동남아만”, “서유럽만” 처럼).


## 기술 노트

- **단일 파일.** 지도 데이터(각국 폴리곤 + 한글/영문/약자/별칭)를 `index.html` 안에
  JSON으로 내장하고, 로드 시 SVG `<path>`/`<circle>` 로 그립니다. 외부 요청은
  Gowun Dodum 웹폰트(Google Fonts) 하나뿐이며, 로드에 실패하면 시스템 글꼴로 자동
  대체되어 오프라인에서도 문제없이 동작합니다.
- 지도는 **정거원통도법(equirectangular)** 으로, 데이터 생성 단계에서 좌표를 미리
  투영·반올림(소수 2자리)해 파일 크기를 줄였습니다.
- 국경 데이터는 공개 데이터셋
  [`johan/world.geo.json`](https://github.com/johan/world.geo.json)
  (Natural Earth 기반, 퍼블릭 도메인)을 사용했습니다.
- 지역·하위 지역은 ISO 코드 목록으로 구성해 데이터를 다시 만들지 않아도 됩니다.
  대륙 경계는 지리 기준(러시아=유럽, 튀르키예·카자흐스탄=아시아 등)으로 나눴습니다.
- 입력 매칭은 대소문자·공백·기호를 제거해 정규화한 뒤(한글/영문/숫자만 비교),
  이름·별칭·ISO 2·3자리 코드를 하나의 표로 조회합니다. 별칭 충돌은 빌드 시 검사합니다.
- 확대/축소·이동, 손가락 오므리기(핀치) 줌, 지역 맞춤 보기는 모두 SVG `viewBox` 를
  부드럽게 보간해 구현했습니다. 아이콘은 인라인 SVG, 국기는 유니코드 이모지입니다.
- **국가 통계(힌트·순위표용)** 는 공개 데이터셋을 빌드 시점에 병합해 내장했습니다:
  인접국·면적·수도·좌표·내륙국 여부는
  [`mledoze/countries`](https://github.com/mledoze/countries), 인구·GDP는
  세계은행(World Bank) 데이터([`datasets/population`](https://github.com/datasets/population),
  [`datasets/gdp`](https://github.com/datasets/gdp)), 평균 고도·평균 기온·정부 형태는
  [`samayo/country-json`](https://github.com/samayo/country-json)을 사용했습니다.
  정부 형태·수도는 한국어로 번역해 힌트에 표시합니다.
- **전쟁 트리비아 문제**는 잘 알려진 사실을 바탕으로 직접 작성한 4지선다 문항입니다
  (**13개 전쟁 · 총 351문항**, 전쟁마다 26~28문항). 연도 암기보다 **원인·전략·전환점·
  조약·인물·결과** 같은 이해형 문제를 중심으로 만들었고, 데이터가 아니라 큐레이션한
  퀴즈예요. 문제 은행은 `index.html` 안에 JSON으로 내장되며, 각 문항의 질문·선택지를
  한국어와 영어로 함께 담아 언어 전환 시 그대로 바뀝니다. 한 판에는 선택한 범위에서
  **무작위 6~15문항**만 뽑아 매번 다르게 출제합니다.
- **다국어(한/영)** 는 UI 문자열과 전쟁 문항을 두 언어로 함께 내장해 구현했고,
  국가별 영어 정부 형태·영어 수도·영어 인접국 이름을 통계 데이터에 추가해 힌트
  퀴즈도 영어로 자연스럽게 나오도록 했습니다.
- **로컬 1대1**은 한 기기에서 턴을 번갈아 진행하는 방식이라 서버·네트워크가 필요
  없습니다. **음성 입력**은 브라우저 내장 Web Speech API를 쓰고, 인식 결과는 편집
  거리 기반 **퍼지 매칭**으로 가장 가까운 나라에 관대하게 맞춥니다(지원 브라우저에서만
  버튼이 보이며, 마이크 권한이 필요합니다).
- **마커 크기**는 현재 `viewBox` 폭에 비례해 매 프레임 조절하여, 확대해도 화면상
  크기가 대체로 일정하게 유지되도록 했습니다.
- **힌트 퀴즈의 역사·분쟁 단서**는 잘 알려진 사실을 바탕으로 직접 큐레이션해 나라별로
  내장했고(나라 이름은 노출하지 않도록 작성), **면적 순위 단서**는 로드 시 전 세계
  나라를 면적으로 정렬해 순위를 매긴 뒤 상위 10/25/50/75/100/150위 구간으로 표현합니다.
- **일부러 넣지 않은 지표**: “정치적 힘·승전/패전 횟수·정치 성향·세금” 은 **객관적이고
  신뢰할 수 있는 공개 데이터가 없어**, 지어내지 않고 뺐습니다(수치를 만들어 넣으면
  부정확·오해 소지가 큽니다). 대신 검증 가능한 지표만 담았고, 원하시면 출처가 명확한
  세율/고도 데이터를 큐레이션해 추가할 수 있습니다.
